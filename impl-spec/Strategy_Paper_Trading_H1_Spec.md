# ТЗ: запуск стратегий на виртуальном счёте с обновлением по H1

**Цель:** запустить текущую E50-стратегию в режиме paper trading. По постоянной ссылке показывать актуальный график, разметку, заявки, сделки и состояние виртуального счёта. Реальные ордера брокеру не отправлять.

## 1. Движок

- Использовать общую логику стратегии для бэктеста и live-режима, без дублирования.
- Подключать новые стратегии через единый интерфейс: закрытая свеча + состояние → разметка и торговые команды.
- Настройки запуска: стратегия и её версия, инструмент, начальный баланс, размер позиции, торговые расходы.

## 2. Обработка данных

- Автоматически получать каждую завершённую H1-свечу; обрабатывать её ровно один раз.
- H1 — шаг обновления и моделирования исполнения. Таймфрейм ZigZag и дневные сигналы на клиринге сохранить согласно настройкам стратегии.
- Перед запуском загрузить историю для расчёта разметки; исторические сделки не проводить по новому счёту.
- Сохранять состояние. После перезапуска последовательно обрабатывать пропущенные свечи без повторных сделок. Показывать задержку данных.

## 3. Виртуальное исполнение

- Учитывать рыночные и лимитные входы, TP/SL, досрочные выходы, расходы, баланс, equity и P&L.
- Сигнал по закрытию исполнять по первой доступной цене после него, без использования будущих данных.
- Касания заявок и TP/SL определять по H1 OHLC. При неоднозначной последовательности использовать консервативное исполнение; при возможном одновременном TP/SL — SL первым.
- Новые заявки не исполнять задним числом внутри уже обработанной свечи.

## 4. Первая стратегия

Подключить последнюю согласованную E50-стратегию:

- вход по дневному пересечению E50;
- TP = MZ0; SL = `2 × цена входа − MZ100`;
- досрочный выход после двух последовательных дневных закрытий со стороны вершины относительно исходного E50;
- после каждого TP — новая зона от E50 предыдущей, без ограничения числа поколений;
- лимитные входы дочерних зон и приоритет ZigZag — по существующей спецификации.

## 5. Страница по ссылке

- График: свечи, ZigZag, якоря, зоны MZ0–MZ100, E50, заявки, входы/выходы, TP/SL.
- Состояние: ожидание сигнала, лимитная заявка, открытая позиция, первое предупреждение о выходе; номер поколения дочерней зоны.
- Баланс, equity, текущий и реализованный P&L, история сделок.
- Время последней обработанной свечи и журнал причин входа, выхода, создания и отмены зон.
- Автообновление после обработки H1; работа сервера не зависит от открытого браузера.

## Приёмка

Последовательное воспроизведение одинаковых H1-данных в бэктесте и live-движке даёт одинаковые события и сделки. Перезапуск не меняет результат и не создаёт дубликаты. По ссылке видны актуальная разметка и состояние счёта.
